# Security Policy

## Supported versions

This policy covers the current static website published from this repository.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.
Report them through [GitHub private vulnerability reporting](https://github.com/VibeBB/www.vibebb.org/security/advisories/new).
Include the affected page or asset, reproduction steps, and an impact
assessment if known. Maintainers will coordinate remediation and disclosure
with you before publishing details.

## Scope notes

The scope is the static site at `www.vibebb.org`, including its HTML, styles,
client-side scripts, and static assets in this repository.
